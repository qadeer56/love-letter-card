# 💌 Interactive Love Letter Card

An interactive, responsive, and beautifully animated web-based Love Letter Card built with pure **HTML5**, **CSS3**, and **JavaScript**.

---

## ✨ Features
* ✉️ **Interactive Envelope Animation:** Smooth opening and closing sequences using CSS keyframes.
* ⏳ **Live Relationship Counter:** Tracks elapsed time dynamically down to seconds.
* 🎵 **Background Music:** Automatic background audio integration upon opening.
* 🌸 **Floating Hearts Effect:** Dynamic canvas/CSS floating animations.
* 📱 **Fully Responsive:** Optimized for both mobile devices and desktop screens.
